## 三、先认识这几个 C++ 概念

- `class PID`：定义一种类型，类似带有操作函数的结构体。
- `public`：外部可以调用的接口，例如 `update()` 和 `reset()`。
- `private`：对象内部保存的参数、状态和辅助函数，外部不能直接修改。
- 构造函数 `PID(...)`：创建对象时执行，用来设置该对象的参数。
- `PID::update(...)`：表示这是 PID 类的成员函数，它能访问当前对象的成员变量。
- 变量名末尾的 `_` 只是命名习惯，用于区分成员变量与传入参数，不是 C++ 的特殊运算符。

例如，`PID speedPid(2.0f, 1.0f, 0.1f, 0.1f, 100.0f, 10.0f);` 创建一个控制器对象。之后通过 `speedPid.update(target, feedback)` 进行计算，通过 `speedPid.reset()` 清除历史状态。`f` 表示 float 常量。

控制器应在重复计算之前创建一次。每次循环都重新创建对象，会丢失积分和历史反馈。

## 四、参数、单位与计算约定

记被控量单位为 Y，控制输出单位为 U，时间单位为秒。target 和 feedback 必须使用相同单位。反馈是测到的被控量，返回的 u 是控制器给出的指令，两者不必使用相同单位。

| 参数 | 含义 | 单位或范围 |
| --- | --- | --- |
| kp | 比例增益 | U/Y，本作业取非负数 |
| ki | 积分增益 | U/(Y·s)，本作业取非负数 |
| kd | 微分增益 | U·s/Y，本作业取非负数 |
| dt | 固定计算周期 | 秒，必须大于 0 |
| outputLimit | 最终控制输出的绝对值上限 | U，正数，输出范围为 ±outputLimit |
| integralLimit | 保存的积分输出 I 的绝对值上限 | U，正数，积分范围为 ±integralLimit |

例如 dt=0.01 表示每次计算代表经过 10 ms，不能传入 10。本作业使用固定周期：一次 update() 代表一个 dt 时间步，不在函数内 sleep，也不读取系统时钟。测试中的两次调用可以紧挨着执行。

假设所有输入均为有效有限数值，不要求写参数异常处理。本作业配置创建后不改变，不要求实现在线修改增益或自动整定。控制方向假设为正输出使反馈增大，误差统一定义为 target−feedback。

**integral_ 保存的是已乘 ki 的积分输出 I，不是原始误差和。** 总输出合成时直接加 integral_，不要再次乘 ki。与原课件中 `fpSumE += fpE; fpUi = fpKi * fpSumE;` 的存储约定不同，本作业统一显式使用 dt，不能混用同一组系数或限值。

## 五、基础任务：完成 update()

按以下约定实现，每一步都应能用自己的话解释。

1. 计算误差：`error = target - feedback`。
2. 计算比例项：`P = kp_ * error`。
3. 更新积分状态：`integral_ += ki_ * error * dt_`。
4. 把 integral_ 截断到 `[-integralLimit_, +integralLimit_]`，并写回 integral_。
5. 计算微分项。首次调用时 `D=0`；其他时候 `D = -kd_ * (feedback - lastFeedback_) / dt_`。
6. 合成 `u = P + integral_ + D`，然后对 u 做 outputLimit_ 限幅。
7. 在本次微分计算完成后，保存本次 feedback，并更新 firstUpdate_ 标记。
8. 返回最终的 u。

clamp(value, minValue, maxValue) 已提供：小于下界取下界，大于上界取上界，否则保留原值。积分限幅和输出限幅应分别做，不能相互替代。

微分采用测量值差分，前面有负号。当目标不变而反馈快速上升时，D 通常为负，可减弱继续推高反馈的作用。仅改变目标、反馈不变时，这种写法不会因目标阶跃直接产生微分突跳。

基础版暂不加入微分滤波、积分分离、按输出饱和条件暂停积分或反算抗饱和。按这里的固定公式完成后再做提高题，保证基础测试的计算约定一致。积分限幅也不意味着已解决所有输出饱和问题。

## 六、基础任务：完成 reset()

reset() 应执行以下动作：

- integral_ 清零。
- lastFeedback_ 清零。
- firstUpdate_ 恢复为 true，让下一次调用的 D 为 0。
- 所有增益、周期和限幅参数保持不变。

不要在每次 update() 开头调用 reset()。正常误差变为 0 时，也不要自动把积分清零，已有积分可能正在提供维持目标所需的输出。

## 八、提高任务：加入积分分离（选做，加分）

完成基础任务后，增加可开启和关闭的积分分离。建议自行增加以下接口及必要的私有成员：

```cpp
void setIntegralSeparation(float errorThreshold);  // 开启，阈值 >= 0，单位 Y
void disableIntegralSeparation();                 // 关闭，恢复通常的积分累加
```

要求：

1. 默认关闭积分分离，保持基础测试全部通过。
2. 开启后，只有 `|error| <= errorThreshold` 时更新积分，否则保留旧 integral_。
3. 暂停累加时，已有 integral_ 仍参加总输出，不清零、不屏蔽。
4. 积分限幅和总输出限幅始终保留。
5. reset() 只清状态，保留积分分离的启用状态和阈值，和其他配置参数遵循相同规则。
6. 自行补充测试，至少覆盖大误差、阈值边界、重新进入积分区、关闭分离后的恢复，以及复位。

建议自检例子：Kp=Kd=0、Ki=1、dt=1，积分限值为 10，输出限值为 100，分离阈值为 3。依次输入误差 `8、3、2、8、−2`，积分输出应为 `0、3、5、5、3`。第四次调用时，误差虽然又变大，但已有 I 应保持为 5。随后关闭积分分离，再输入误差 8，应更新并限幅为 10。

阈值判断使用原始误差，本作业没有额外的误差限幅。阈值过小可能一直进不了积分区，单纯增加 Ki 也无效。冻结已有积分还可能妨碍大误差时的恢复，因此它不能替代完整的抗饱和设计。

指定参数：Kp=2，Ki=1，Kd=0.1，dt=0.1，输出上限100，积分上限10。

1. 第一次 update(10, 8)
   error = 10 - 8 = 2
   P = 2 * 2 = 4
   I = 0 + 1 * 2 * 0.1 = 0.2
   第一次调用没有历史反馈，所以 D = 0
   u = 4 + 0.2 + 0 = 4.2

2. 第二次 update(10, 9)
   error = 10 - 9 = 1
   P = 2 * 1 = 2
   I = 0.2 + 1 * 1 * 0.1 = 0.3
   D = -0.1 * (9 - 8) / 0.1 = -1
   u = 2 + 0.3 - 1 = 1.3

3. reset() 后再次 update(10, 8)
   reset() 将积分清零并恢复首次调用标记，但保留所有配置参数。
   因此 P = 4，I = 0.2，D = 0，u = 4.2。

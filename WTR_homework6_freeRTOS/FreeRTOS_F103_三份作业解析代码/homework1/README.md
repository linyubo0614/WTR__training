# 作业一

只将本文件夹 UserCode 中的文件加入工程。不要同时加入三个作业的 cpp。

1. 用根目录的公共 ioc 配置生成工程，InitTask 入口填小写 init。
2. HW1_FIX_MODE 改为 0，编译、下载、复位，记录竞争版本的 counter。
3. HW1_FIX_MODE 改为 1，再编译、下载、复位。期望结果 33554432。
4. 需要保留附件的4字节输出时，HW1_TEXT_OUTPUT 改为 0，串口助手开十六进制接收。
5. 互斥量替代方案为 HW1_FIX_MODE=2。它比短临界区更慢，但也应得到正确结果。

正确结果的小端字节为 00 00 00 02。竞争版本偶尔正确，不证明它线程安全。

本代码做过电脑端 C++11 语法检查，尚未在你的板上烧录。阅读配套讲解后实测。

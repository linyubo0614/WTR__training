# 作业二

按 100、240、300、350、500 依次修改 WRITE_WAIT_US。每次重新编译、下载、复位。
串口助手配置 115200、8N1，文本模式。输出2000个字符后会有 A/B 数量、段数和UART返回状态。

UART_TIMEOUT_MS 默认300。原附件100ms无法在115200下发送完2000字节。
这个修改只影响最终串口观察，不改变两个写入任务之间的竞争。
本版本还增加了用于调试的计时变量，微秒级实验中这些语句也会影响边界。
需要严格比较原版时，请移除hw2_point/hw2_*时间记录语句，保留等待参数与A/B逻辑。

先不设断点记录结果，再复位用 BP1..BP6 分析执行顺序。最后查看 memset 的反汇编，
因为函数入口/出口的断点不能证明2000字节的具体写入顺序。

请填写 experiment_record.md，不要把示意时序当成实测结论。
